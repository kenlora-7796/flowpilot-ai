# FlowPilot AI — Project Scope

## Project
FlowPilot AI by Tierra AI Labs

## Intended Users
Small business owners who need help organizing everyday work.

## Problem
Business owners often describe what they need to do in plain language but struggle to turn those requests into organized, prioritized tasks.

## Core Experience
1. Enter a business request in plain English.
2. Generate a structured workflow.
3. Display tasks with priority labels.
4. Mark individual tasks complete.

## Proof of Concept
Demonstrate one request being transformed into a useful task list in a working web application.

## Build Now
- Simple web interface
- Natural-language request input
- AI-assisted workflow generation
- Priority labels
- Task completion checkboxes
- Language selector and Translate button (English and Spanish)

## Build Later
- Email and calendar integrations
- Automated invoice creation
- Autonomous task execution
- User accounts and saved workflows
- Additional language support

## Success Criteria
A user can enter a request, generate a workflow, review its tasks, translate task descriptions between English and Spanish, and mark tasks complete during a short demo.

## Development Approach
PowerShell, VS Code, AI-assisted development, and free or low-cost tools.
