FlowPilot AI — App Map

A bilingual workflow planner for small businesses.

Application flow

1. Enter a request

The user describes a business goal.

public/index.html
↓
2. Send to the server

The browser submits JSON to POST /api/workflow.

public/app.js
↓
3. Generate tasks

The Node.js server validates input. Without a Gemini API key, it returns clearly labeled sample tasks. With a configured key, it requests tasks from Gemini and validates the response.

server.js
↓
4. Track progress

The browser displays priorities and interactive checkboxes. Completion progress updates without changing task IDs.

public/app.js and public/style.css
↓
5. Switch languages

The browser sends tasks to POST /api/translate. Demo mode displays generic Spanish examples; configured Gemini mode requests translations. The original English descriptions and checkbox completion states are preserved.

public/app.js and server.js

Important files

  • server.js — HTTP server, API routes, validation, Gemini integration
  • public/index.html — Dashboard structure
  • public/app.js — User interactions and task state
  • public/style.css — Responsive interface and accessibility styling
  • server.test.js — Automated application tests
  • devpost/ — Project planning and learning documentation

Limitations and next improvements

  • Demo translations are examples, not complete translations of arbitrary requests.
  • Task progress is held in browser memory and resets on page reload.
  • Live Gemini generation and translation require a valid API key.
  • Potential future work: saved workflows, export, and more languages.

Learning reflection

The browser collects input, the server validates it, and the resulting tasks return as JSON. The interface renders those tasks and manages completion state. Translation changes the displayed descriptions without replacing the original tasks.
